# MineCode artwork

Original artwork, MIT-licensed with the rest of MineCode. No Minecraft textures, screenshots, third-party logos or font files are bundled.

| Asset | Purpose |
| --- | --- |
| `minecode-demo.gif` | Restrained illustrative question / evidence / decision loop |
| `minecode-demo.png` | Static evidence frame, also available for readers who prefer no motion |
| `architecture.svg` | Editable vector diagram of the host, skills, MCP runtime and project boundaries |

Palette: deepslate `#101419`, panel `#191F26`, stone `#A6B1AD`, emerald `#83C6A1`, violet `#AEA1DC`, blue `#819ABF`. Use readable system sans-serif and monospace type, consistent spacing and small block details. The visuals have opaque backgrounds for light and dark README contexts. SVG text uses local system fallbacks; no fonts are fetched.

The animation was drawn locally with Pillow and system fonts. It illustrates a workflow, not a terminal recording. Its Minecraft 1.21.11 / Yarn 1.21.11+build.3 mapping fields were checked through `search_reference_code` and `get_reference_context` against independently sourced CC0 records. The example identifies `InGameHud.render(DrawContext, RenderTickCounter)`; a mapping is not a Minecraft implementation body or proof that a Mixin repair ran in game.

See [retrieval](../RETRIEVAL.md) for evidence boundaries and [third-party notices](../../THIRD_PARTY_NOTICES.md) for source rights. These visuals add no runtime or development dependency to MineCode.
